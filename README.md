# Habit Tracker

This branch is a clean rebuild foundation.

- The animated TypeScript splash screen is the only retained feature component.
- After the splash, the app displays a minimal **Hello World** screen.
- App runtime code uses TypeScript (.ts / .tsx).
- The root DESIGN.md remains the design source of truth.
- No analytics, prayer tracking, location features, or legacy screens are included.

## Run locally

    pnpm install
    pnpm start

Type-check with `pnpm typecheck`.
